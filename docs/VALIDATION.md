## 补传与离线管理

- 空积压自动退出，配置的 TCP 端口被占用时仍可仅补传。
- 混合 PENDING/SENDING/RETRY 恢复并转发；既有 ACKED、DEAD 保持不变。
- RETRY 尚未到期时继续等待，到期后补传。
- 接收端不可连接时保留消息并重试，SIGTERM 后正常停止；恢复连接后再次补传。
- DEAD 导出遵守同一数据库的实例锁，保留完整字段，不更新业务状态。
- 已有目标文件、数据库本身及非法模式组合受到保护或被拒绝。
